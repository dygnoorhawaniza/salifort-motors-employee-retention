# 🌸 About this project

### Salifort Motors — Employee Retention

A portfolio project focused on **HR analytics and predictive modeling**.

The project explores employee turnover using a dataset containing job satisfaction, performance evaluation, workload, project count, tenure, promotion history, department and salary.

### What I worked on

- Cleaned and explored employee data
- Investigated relationships between workload, satisfaction, tenure and turnover
- Built a logistic regression baseline
- Built decision tree and random forest classifiers
- Applied feature engineering to reduce potential data leakage
- Evaluated models using precision, recall, F1, accuracy and AUC
- Interpreted feature importance
- Translated model findings into HR-focused recommendations

### Main question

**What patterns in the employee data can help HR understand and anticipate employee turnover?**

### Dataset note

The repository contains the supplied analysis notebook and exported visualizations. The raw CSV is intentionally not bundled here; add `HR_capstone_dataset.csv` locally before running the notebook.
